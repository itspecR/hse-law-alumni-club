# Изменения в праве

Реализовано 22.09.2026 по запросу владельца: автоматическая ретрансляция опубликованных материалов [LegisDigest](https://t.me/LegisDigest) в `/changes`. Исходный проект: https://github.com/Bogolubov-creator/legis-digest. В первом импорте 16 справок и обзоров; отдельно сохранён архив из 65 актов за 30.06–06.07.2026.

## Чтение

По умолчанию открываются справки и обзоры: краткий фрагмент в списке и полный исходный текст в карточке. Сохраняются абзацы, подзаголовки и допустимые ссылки на источники. Новые пояснения сайт не генерирует. Автоматические материалы подписаны именем источника, проверка человеком не подтверждена; публикация в канале не означает одобрение юристом. Владелец выбрал автоматическую ретрансляцию с указанием источника и отсутствия проверки человеком.

Поиск работает по всему тексту. Тип материала, период и режим просмотра сохраняются в URL. Постоянный адрес `/changes/tg-9` открывает конкретную справку; исходный пост доступен по отдельной ссылке. Архив актов остаётся самостоятельным режимом. Неизвестные даты вступления в силу не вычисляются из текста обзора.

## Обновление архива

Раздел скрыт флагом `CHANGES_ENABLED` в `frontend/club_web/features.py`.
Архив обновляется вручную командой из корня монорепозитория:

```bash
uv run --directory frontend python -m club_web.sync_changes --output ../data/changes.json
```

Импортер читает прежнюю базу из файла `--output`, получает открытую ленту
`https://t.me/s/LegisDigest` и объединяет записи по идентификатору поста.
Импорт не требует Telegram-токена, доступа к подписчикам или LLM-вызовов.
Обычная сборка сайта использует включённый JSON.

## Сохранность и ограничения

Повторный импорт не создаёт дублей, доступные исправленные посты заменяют старую версию. Записи, вышедшие за окно ленты, сохраняются; исчезновение из окна не трактуется как удаление. История прежних редакций текста отдельно не хранится. Обход ограничен десятью страницами. Удалённые посты автоматически не удаляются из накопленного архива.

Импортер проверяет канал, даты, уникальность, размер и схему. Разметка разбирается инертно и выводится экранированным текстом Jinja2. Допустимы только HTTPS-ссылки из списка источников; HTTP-ссылки официального `publication.pravo.gov.ru` переводятся на HTTPS. Запись файла атомарная.

При ошибке ленты сохраняются прежние материалы и дата последней успешной загрузки, выставляется статус недоступности. Если прежнюю базу нельзя прочитать из файла, команда останавливается с ошибкой. Нельзя подменять ошибку пустой базой.

Успешная загрузка и дата последнего поста показываются отдельно. При проверке
22.09.2026 последний открытый пост датировался 07.09.2026. Работа исходного
генератора на его сервере этим импортом не проверяется. Интеграция забирает новые
публикации, когда они появляются. Это выборка источника, а не полная база
российского законодательства.

## Проверка

Тесты проверяют реальный формат импорта, текст и ссылки, изоляцию сообщений, повтор/исправление постов, пагинацию, сохранение базы при ошибках и недопустимые данные. Браузерные сценарии проверяют поиск, чтение, возврат, прямую ссылку, режим архива, отдельные даты загрузки и публикации на desktop и iPhone WebKit. Оформление задано в [DESIGN.md](../../DESIGN.md).
