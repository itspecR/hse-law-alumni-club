# Каталог ДПО с сайта Центра ДПО

Программы ДПО реализует Центр ДПО факультета права, сайт клуба только показывает
их и рассказывает о скидке выпускникам. Каталог полностью берётся с сайта Центра
ДПО (репозиторий `itspecR/dpo-pravo-hse-v2`), вручную программы ДПО на сайте клуба
не добавляются.

## Откуда и как часто

Сервер клуба в 41-ю минуту каждого часа запрашивает `GET /api/catalog/programs` у
адреса из `DPO_SITE_URL`. Ответ – JSON со списком карточек: номер hse.ru (`hse_id`),
название, направление, формат, длительность, подпись старта («Старт: …»), подпись
цены («45 000 ₽», «Цена по запросу», «Бесплатно»), обложка и путь к странице
программы на сайте Центра ДПО.

- Программа с тем же номером hse.ru обновляется на месте: адрес на сайте клуба,
  сохранённое и старые заявки не теряются.
- Новая программа добавляется опубликованной.
- Программа, которой больше нет в ответе, и программы ДПО без номера (созданные
  вручную или старым импортом) снимаются с публикации, но не удаляются.
- Цена без суммы («Цена по запросу») остаётся пустой, и сайт клуба пишет
  «Стоимость уточняется»; «Бесплатно» сохраняется как 0. Формат «смешанный» и
  «гибридный» становится смешанным, неизвестный формат остаётся пустым.
- Обложки скачиваются в «Медиа» с паузой 1 секунда; новая обложка заменяет прежнюю,
  если сменился её адрес на сайте Центра ДПО.

## Защита от сбоев

Если сайт Центра ДПО не ответил, вернул меньше 3 программ или меньше половины
опубликованных сейчас, список на сайте клуба не меняется. Время проверки, число
программ и текст ошибки хранятся в таблице `club_dpo_sync`. После 3 неудачных
проверок подряд сотрудникам один раз уходит уведомление тем же каналом, что и о
заявках.

## Запуск на сервере

1. Применить миграции штатным `scripts/migrate.sh`.
2. В окружении API задать `DPO_SITE_URL=https://<домен сайта Центра ДПО>` и
   пересоздать контейнер API. Нужен домен с настоящим сертификатом: проверку TLS
   сервер клуба не отключает.
3. Проверить вручную: кнопка «Обновить каталог ДПО» в панели, `POST /admin/dpo-sync`
   от администратора или команда оператора `sync-dpo`.

## Сайт Центра ДПО на IP с самоподписанным сертификатом

Пока у сайта Центра ДПО нет домена, он работает по IP и порту с самоподписанным
сертификатом (`scripts/setup-https.sh` в его репозитории). Такой адрес принимается
только вместе с этим сертификатом в `DPO_SITE_CERTIFICATE`: проверка TLS остаётся
включённой, но для сайта ДПО сервер клуба доверяет только ему, а не общему списку
удостоверяющих центров. Адрес с портом без сертификата не принимается.

Ссылки на карточках строятся от `DPO_SITE_LINK_URL`, если он задан, иначе от
`DPO_SITE_URL`. Это нужно, когда сервер за NAT: изнутри внешний адрес недоступен,
поэтому каталог и обложки скачиваются по внутреннему адресу, а посетители
переходят по внешнему. Во внутреннем адресе должен быть IP, записанный в
сертификат (скрипт сайта ДПО вписывает `127.0.0.1` и адреса сервера), и этот же
адрес должен быть в `DJANGO_ALLOWED_HOSTS` сайта ДПО, иначе он отвечает 400.

Пример для установки с MariaDB (настройки API в `/etc/club/runtime.env`), когда
сайт ДПО стоит на той же виртуальной машине: внутренний адрес `192.168.3.155`,
снаружи сайт открывается как `62.112.123.10`.

```bash
sudo sed -i '/^DPO_SITE_URL=/d;/^DPO_SITE_LINK_URL=/d;/^DPO_SITE_CERTIFICATE=/d' /etc/club/runtime.env
echo "DPO_SITE_URL=https://192.168.3.155:8443" | sudo tee -a /etc/club/runtime.env > /dev/null
echo "DPO_SITE_LINK_URL=https://62.112.123.10:8443" | sudo tee -a /etc/club/runtime.env > /dev/null
echo "DPO_SITE_CERTIFICATE=$(sudo base64 -w0 /etc/dpo/tls/fullchain.pem)" | sudo tee -a /etc/club/runtime.env > /dev/null
./scripts/deploy.sh
```

Если сайт ДПО на другом сервере, `fullchain.pem` копируется оттуда; закрытый ключ
`privkey.pem` серверу клуба не нужен. В установке с PostgreSQL строки пишутся в
файл Compose (`/etc/club/compose.env`). После выкладки нажать «Обновить каталог ДПО».
Внутренний адрес должен быть постоянным: если машина получит другой IP, загрузка
остановится с ошибкой связи.

Сертификат сайта ДПО действует 825 дней. После его перевыпуска строку
`DPO_SITE_CERTIFICATE` нужно заменить, иначе загрузка остановится с ошибкой связи.
Посетители, открывшие программу на сайте ДПО, увидят предупреждение браузера о
сертификате, пока у сайта ДПО нет домена.

Когда сайт ДПО переедет на домен с настоящим сертификатом, задать
`DPO_SITE_URL=https://<домен>`, удалить строки `DPO_SITE_LINK_URL` и
`DPO_SITE_CERTIFICATE` и выполнить выкладку. Программы обновятся на месте по номеру hse.ru, ссылки поменяются на домен.

Пока `DPO_SITE_URL` пуст, загрузка выключена и мониторинг её не ждёт.

## Панель и корзина

В панели раздел «ДПО» только для просмотра: `GET /admin/programs` отдаёт список,
`GET /admin/dpo-sync` – задан ли адрес, включена ли загрузка и итог последней
проверки. Создавать, менять и удалять программы ДПО нельзя. Корзина принимает
только мерч, программы ДПО оформляются на сайте Центра ДПО.
