# Прямые ссылки мини-приложения клуба

Ссылка предпросмотра: `/tg?startapp=dpo`.

После настройки Main Mini App у бота через BotFather можно использовать
`https://t.me/pravohse_alumni_bot?startapp=dpo`.
Само изменение фронтенда не настраивает Main Mini App и не запускает обработчик.

Поддерживаемые значения: `club`, `dpo`, `events`, `news`, `podcasts`, `merch`,
`lk`, `support`. Для программы: `p_<slug>` – slug из каталога клуба, например
`p_business-mediation`. Это не числовой идентификатор из стороннего ДПО-приложения;
его формат кампаний `-c_…` здесь не применяется.

Приоритет: SDK `initDataUnsafe.start_param`, затем официальный URL-параметр
`tgWebAppStartParam`, затем `startapp` для предпросмотра. Параметр используется
только для навигации. Вход по-прежнему требует проверки подписанного `initData`
сервером. Внешние URL, путь админки и неизвестные команды игнорируются.

Переход выполняется один раз при запуске на главной или `/tg`. Если человек
уже открыл другой раздел, поздно загрузившийся SDK не меняет его выбор.
Несуществующая программа отображается штатной страницей отсутствующего товара.
Проверки браузера с имитацией SDK не заменяют приёмку внутри Telegram на телефоне.

Основание: https://core.telegram.org/bots/webapps (проверено 14.09.2026).
