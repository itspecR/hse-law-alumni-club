# Правовые документы сайта

Подготовленная редакция: 6 ноября 2026 года. Публикация требует подтверждения
оператором фактических сведений ниже. Проверка исходного кода не подтверждает
организационные меры, договоры с подрядчиками или размещение рабочих баз.

## Документы и формы

| Адрес | Назначение |
|---|---|
| `/terms` | Правила сайта, кабинета, заявок, подписки и мобильной версии |
| `/privacy` | Цели, данные, основания, получатели, хранение и права пользователя |
| `/consent#registration` | Отдельное согласие для регистрации и сообщества |
| `/consent#order` | Отдельное согласие для заявки |
| `/support/consent` | Ссылка на самостоятельное согласие, показываемое формой поддержки |
| `/confidential` | Краткое изложение правил конфиденциальности со ссылкой на политику |
| `/requisites` | Сведения об операторе и различие оператора и исполнителя обучения |

Реквизиты и дата редакции находятся в `data/legal-data.json`. Один файл входит
в пакеты API и web. Регистрация записывает эту версию только для нового согласия;
старые записи не меняются. Замена текста не расширяет прежнее согласие. При
расширении целей для прежних участников оператору нужно определить основание
и, если требуется, получить новое согласие до такой обработки.

Согласие в регистрации и корзине не отмечено заранее и не объединено с принятием
соглашения. Новая обязательная отметка принятия соглашения не добавлена; механизм
его акцепта и применение к существующим аккаунтам нужно определить до публикации.
Для поддержки сохраняются полный текст и версия, полученные при создании обращения.
Для заявки сохраняются отметка согласия и дата заявки, но отдельной версии согласия
в записи заказа сейчас нет. До рабочей публикации нужно обеспечить доказательство
того, какой текст был показан заявителю; нельзя приписывать старым заявкам новую версию.

## Соответствие функциям

| Область | Проверенный источник | Что отражено в документах |
|---|---|---|
| Регистрация | `backend/club_api/modules/auth/routes.py` | Поля анкеты, отдельное согласие, дата и версия |
| Кабинет | `backend/club_api/modules/members/profile.py` | Контакты, образование и обезличивание при удалении; выгрузки в кабинете нет |
| Сообщество | `backend/club_api/modules/members` | Ограниченная видимость профиля для однокурсников, без телефона и почты |
| Заявки | `backend/club_api/modules/checkout` | Контакты, доставка, договорные основания, проверка суммы и оплаты |
| Поддержка | `backend/club_api/modules/support` | Отдельное согласие, доступ по коду, чтение переписки администраторами |
| Telegram | `backend/club_api/modules/telegram` | Отдельная привязка, идентификаторы и выбранные функции |
| Мониторинг | `backend/club_api/observability/errors.py` | При включении передаются только разрешённые коды и атрибуты событий |
| Локальные данные | `frontend/club_web/browser` | Настройки, сохранённое, выбор cookies, публичные офлайн-копии |

Сроки 1095 дней для контактных полей заявок, 30 дней для поддержки и 365 дней
для журнала соответствуют базовым настройкам. До выпуска сверить их с конфигурацией
целевого сервера и утверждёнными сроками оператора. Срок очистки сам по себе
не создаёт основания хранения. Удаление аккаунта не означает удаления всех
договорных записей или немедленного уничтожения всех резервных копий.

## Что подтверждает оператор до выпуска

1. Наименование, адрес и полномочия АНО. Реквизиты сохранены из репозитория;
   совпадение с открытой карточкой контрагента не заменяет актуальную выписку ЕГРЮЛ.
2. Рабочий адрес электронной почты для обращений и отзыва согласия. Сейчас
   оставлен имеющийся почтовый адрес; неизвестный email не подставлен.
3. Фактических получателей данных и поручения обработки: хостинг, почта,
   платёжный сервис, Telegram и мониторинг, если включены; страны обработки,
   необходимые уведомления Роскомнадзора и допустимость выбранных каналов.
4. Сроки хранения по целям, очистку рабочих данных и копий, порядок выполнения
   запросов и запрет возврата удалённых данных после восстановления.
5. Порядок принятия соглашения и подтверждение новых согласий, если они нужны
   для существующих участников. Это решение не заменяется обновлением даты в файле.
6. Исполнителей платных услуг, условия оплаты, возврата и документы по программам.

## Публикация и проверка

После подтверждения сведений выпустить API и web одной ревизии по
[runbook](deploy-runbook.md), проверить все правовые страницы и ссылки из регистрации,
корзины и подвала. Выполнить одну синтетическую регистрацию и сверить дату и версию
в согласии; не менять исторические согласия. Проверить форму поддержки с фактической
конфигурацией. Зеркало собирается отдельно и не доказывает работу этих форм.
Откат кода описан в runbook; он не отменяет уже полученные согласия и обязательства.
